# Stockroom: frontend

React + Vite client. See the [main README](../README.md) for the full project guide.

```powershell
npm install
npm run dev      # http://localhost:5173  (start the Flask backend first)
npm test         # run the tests
```

Vite forwards `/auth` and `/inventory` to `http://localhost:5000` (see `vite.config.js`).
